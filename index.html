Game Development Design

Welcome to GDD! The purpose of this website is to teach concepts about game development in a more generalized way. I will be covering topics that are not necessarily specific to any one programming language or game engine, but rather concepts that can be applied to any programming language or game engine.

About the Author

My name is Ozald. I am currently a Computer Science student that is pursuing game development as a hobby and, hopefully, a career someday.

I've noticed that there is a distinct lack of resources that centralize game design patterns and concepts on a single website. Furthermore, as I've met beginners throughout the teams I've joined, I've noticed that a lot of concepts that would be useful to know for effective project scalability are just not taught often. Many videos focus on "how to" content which, while great for beginners, may fail in the context of a large project. I firmly believe that anybody can become a game developer, but knowing proper software engineering design patterns and programming paradigms can make game development much less stressful whenever bugs show up or when you need to change the code later on.

This website is to bridge this gap in knowledge. Not only are there several chapters in this website dedicated to each individual concept I describe and how they relate to game development, but I will also include any resources (PDFs, videos, websites, etc.) I find that I feel provide great explanations about each individual topic. I hope the knowledge this website contains boosts your capability as a game developer as much as it has for me.

This website is currently in WIP. Many of the chapters on this website are subject to change. I am planning on allowing pull requests so that if there are any mistakes or new concepts that can be explained, this website can evolve even as I work on other projects. I want this site to be a hub for all things related to game development.

Additionally, most of my experience has been in C# and Unity, so some of the examples I provide may be in those. However, the concepts I explain are not limited to these two, and I will try to provide examples in other languages and engines as well. Again, once this website is more complete, I will allow pull requests so that others can contribute to this website and make it a more complete resource for all game developers beyond Unity.
